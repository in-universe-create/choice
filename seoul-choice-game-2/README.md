# Seoul Choice Game

## 데이터 구조

각 스토리는 독립된 JSON 파일 하나로 관리합니다.

```text
data/
  stories/
    seoul_2033.json
    another_story.json
```

스토리 파일 하나 안에 해당 스토리의 진영, NPC, 아이템, 능력, 노드가 모두 들어갑니다.

에디터에서는 한 번에 하나의 스토리만 편집하며, 로컬 브라우저 저장과 JSON 내보내기/불러오기를 지원합니다.

## 실행

```bash
npm install
npm run dev
```

## 랜덤 효과

선택지 효과에서 두 종류의 랜덤 시스템을 함께 사용할 수 있습니다.

- **랜덤 효과**: 각 규칙이 입력한 확률로 독립적으로 판정됩니다. 여러 규칙이 동시에 발동할 수 있습니다.
- **확률 테이블**: 테이블마다 여러 결과 중 최대 1개가 선택됩니다. 각 결과 확률을 직접 입력하며, 합계가 100%보다 작으면 남은 확률은 아무 결과도 발생하지 않는 구간입니다.

예: 30% 키워드 / 20% 체력 감소 / 50% 아무 일 없음.


### v15 조건 확장
- 조건부 지문/조건부 노드 이동/조건부 부분 지문에서 플래그, 키워드, 아이템, 스탯 범위, NPC 호감도, 진영 조건을 사용할 수 있습니다.
- `requiredChoices` / `excludedChoices` / `requiredAnyChoices`로 이전 선택 이력을 조건으로 사용할 수 있습니다.
- 조건부 부분 지문은 맨 앞/뒤 삽입, 특정 문구 앞/뒤 삽입, 특정 문구 교체, 특정 문구 삭제를 지원합니다.
- 여러 조건을 함께 설정하면 모두 만족해야 합니다.
